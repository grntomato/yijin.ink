
A personal Hugo blog using the eXtremely Minimal theme by Yihui Xie.

## About

Yijin.ink is my personal website and blog.
It serves as a space to document my thoughts, share knowledge, explore technology, and record things that interest me.

## Live Site

Visit the website: [Yijin](https://yijin.ink)

## Tech Stack

- [Hugo](https://gohugo.io/) - Static site generator
- Markdown - Content authoring
- HTML / CSS - Web structure and styling

## Project Structure

```text
.
├── archetypes/       # Content templates
├── content/          # Website content
│   └── posts/        # Blog posts
├── layouts/          # Page templates
│   ├── shortcodes/   # Custom shortcodes
│   └── _partials/    # Reusable template partials
├── static/           # Static assets
│   ├── css/          # Stylesheets
│   ├── fonts/        # Fonts
│   └── img/          # Images
├── themes/
│   └── hugo-xmin/    # Hugo theme
├── hugo.toml         # Hugo configuration
├── .gitignore        # Git ignore rules
└── .gitmodules       # Git submodule configuration
```
